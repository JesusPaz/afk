# AFK functional POC

## Why

Validate that a Mac-owned shell can be viewed and controlled from a native iPhone client without a VPN or manual port forwarding in the product flow. The eventual default hosted relay is not part of this local POC.

## What changes

Create a monorepo with native Swift apps, shared Swift packages, a Go relay and PostgreSQL from day one. Deliver a bounded vertical slice before the encrypted, distributable MVP.

## Impact

New repository, new wire protocol and initial database schema. No existing service migration. Developer setup only; no public service deployed. See `docs/roadmap.md` for deferred requirements.
