# AFK retro keyboard

Shared Mac/iPhone icon generated with the built-in imagegen tool on 2026-10-16.
Source: `retro-keyboard.png`; regenerate the Apple catalog with
`python3 scripts/release/make-beta-icon.py` on macOS. The source stays opaque;
iOS applies its own icon mask.

Prompt:

> Use case: logo-brand. Create a finished square app icon artwork for AFK, a personal remote terminal app for Mac and iPhone. Subject: one compact retro computer keyboard inspired by 1980s home computers and 8-bit games, with chunky ivory keycaps, a dark charcoal base and a single warm orange return key bearing a simple terminal >_ symbol. Slight top-down isometric perspective, strong bold silhouette, charming precise tactile pixel-inspired geometry, clean premium illustration rather than a photograph. A small set of oversized keys, not a full tiny QWERTY layout. Centered, comfortably fills the central 75% of a square. Solid deep ink blue full-bleed background, subtle purposeful shading. Extremely legible as a small app icon. No letters, no AFK text, no brand logos, no surrounding mockup, no border, no pre-rounded outer corners, no extra objects, no gradients or neon glow. Deliver a single 1024x1024 opaque square final icon.

The generated master is 1254×1254; `sips` resizes it to the catalog dimensions.
